# ATS Resume Review Agent

An interactive ATS resume evaluator powered by IBM watsonx.ai and Watson Machine Learning. Evaluates candidate resumes (plain text or PDF) against target job descriptions, providing an ATS match score, matched/missing skill breakdowns, and actionable bullet rewrites.

## Tech Stack
- **AI / LLM:** Watson Machine Learning deployment (Sydney region)
- **Backend:** Python, Flask, Flask-CORS, PyPDF, Requests
- **Frontend:** HTML5, CSS3, JavaScript
